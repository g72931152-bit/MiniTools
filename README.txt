MINITOOLS
A fast, clean collection of everyday browser tools.

FEATURES
- JSON Formatter — format, validate and minify JSON.
- Base64 — encode/decode UTF-8 text.
- UUID Generator — generate UUID v4 values.
- Hash Generator — SHA-1, SHA-256, SHA-384 and SHA-512.
- QR Generator — create downloadable QR codes.
- Timestamp Converter — convert Unix timestamps and dates.
- Regex Tester — test patterns and replacements.
- Color Converter — convert HEX, RGB and HSL values.
- Image Compressor — resize/compress images locally in the browser.
- Text Cleaner — clean whitespace and empty lines.

RUN LOCALLY
Open index.html in a modern browser.

GITHUB
1. Create a new repository.
2. Upload index.html and README.txt.
3. Commit the files to the main branch.

RENDER STATIC SITE
1. Create a new Static Site on Render.
2. Connect the GitHub repository.
3. Set the build command to: echo "No build required"
4. Set the publish directory to: .
5. Deploy.

GITHUB PAGES
1. Open the repository settings.
2. Enable Pages for the main branch and the root folder.
3. Save the settings and wait for GitHub Pages to publish the site.

PRIVACY
The main tools process input in the browser. There is no account system or application backend in this project.
The QR generator uses a small client-side library loaded from a public CDN. No QR content is sent to that CDN by the page.

BROWSER SUPPORT
Use a current version of Chrome, Edge, Firefox or Safari for the best experience.
